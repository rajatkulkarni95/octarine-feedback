# Octarine Web Clipper Privacy Policy

Last updated: September 15, 2026

Octarine Web Clipper does not collect, transmit to the publisher, sell, or share personal data. It has no analytics, advertising, tracking, account system, or remote content-processing service.

The extension reads web pages only to provide clipping actions requested by the user. Content extraction and Markdown conversion happen locally in the browser. The result is passed directly to the locally installed Octarine desktop application through an `octarine://` deep link.

Extension preferences, destination folders, properties, pending selections, and user-created templates are stored locally using browser extension storage. They are not sent to Octarine's publisher or any third party.

The extension requests access to websites because clipping must work on pages across the web. It does not use that access to build browsing histories. The “Save all tabs” feature reads tab titles and URLs only after the user invokes that action. Browser-restricted pages remain inaccessible.

Website links and images retained in a clip may load from their original hosts when viewed. Octarine Web Clipper does not execute remotely hosted code.

For privacy or support questions, email rajat@octarine.app or use the public [Octarine feedback tracker](https://github.com/rajatkulkarni95/octarine-feedback/issues). Do not post security-sensitive details publicly.
